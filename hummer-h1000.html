Hummer H1000 Portable Power Station

716.8Wh LiFePO4 power station with 1000W pure sine wave AC output and 3,000-cycle battery life. Powers 12 devices via wall, car, or solar.

1000W (2000W surge) AC Output
716.8Wh Capacity
3,000 cycles Battery Life
10kg Weight
Technical Data

Full Specifications

Battery Capacity 716.8Wh (22.4V / 32Ah)
Battery Type LiFePO4 Lithium-ion
Cycle Life 3,000 cycles to 80%
AC Output 2× 220V, 50Hz, 1000W (2000W surge) — Pure Sine Wave
DC/Car Output Regulated + 120W max car port (12V/10A)
USB-C Input PD 100W max
USB-C Output PD 60W max
USB-A Outputs 2× standard (5V/2.4A) + 1× QC 18W max
DC Input 140W max (10–28V, 8A)
Operating Temps Charge: 0–45°C / Discharge: -10–45°C
Dimensions 294 × 185 × 295mm
Weight 10kg
What It Does

Key Features

1000W pure sine wave AC (2000W surge) — full appliance support

LiFePO4 battery — 3,000 cycle lifespan vs 1,000 in standard Li-ion

PD 100W input for rapid recharge (full charge in 4 hours)

Solar panel compatible input

Charges up to 12 devices simultaneously

Real-time LCD battery display

UL-certified with flame-retardant materials
